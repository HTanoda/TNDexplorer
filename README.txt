================================================================================
  TNDexplorer - 超高速ファイル検索ツール
  Version 1.0.0.0
================================================================================

  NTFS MFT を直接読み取ることで、数百万件のファイルを瞬時に検索できる
  Windows デスクトップアプリケーションです。ネットワークドライブにも対応。

  Copyright (c) 2026 TND (Hiroki Tanoda)
  License: MIT


================================================================================
  動作要件
================================================================================

  - Windows 10 / 11
  - .NET Framework 4.8 (Windows 10 1903以降は標準搭載)
  - 管理者権限 (NTFS MFT へのアクセスに必要)


================================================================================
  インストール / 起動
================================================================================

  インストール不要です。TNDexplorer.exe を任意のフォルダに配置し、
  ダブルクリックで起動してください。

  初回起動時に UAC (ユーザーアカウント制御) の確認が表示されます。
  「はい」を選択すると、初期設定ウィザードが開きます。

  ■ 初期設定ウィザード
    - インデックス対象のローカルドライブ(NTFS)を選択
    - ネットワークドライブの検出と有効化(任意)
    - 「開始」ボタンでインデックス作成を開始

  設定は %LOCALAPPDATA%\TNDexplorer\ に保存されます。


================================================================================
  基本的な使い方
================================================================================

  1. 起動するとインデックスの作成が始まります(ステータスバーに進捗表示)
  2. 上部の検索ボックスにキーワードを入力
  3. リアルタイムで検索結果が表示されます
  4. 結果をダブルクリックするとファイルが開きます

  ■ フィルタ (検索ボックス右側)
    [すべて]  [ファイル]  [フォルダ]
    表示する項目の種類を切り替えます。


================================================================================
  検索構文
================================================================================

  ■ AND検索 (スペース区切り)
    例: report 2024
    → 「report」と「2024」の両方を含むファイル名を検索

  ■ OR検索 (パイプ | 区切り)
    例: ext:txt|ext:doc
    → .txt または .doc のファイルを検索

  ■ AND + OR の組み合わせ
    例: ext:txt|ext:doc report
    → (.txt または .doc) かつ「report」を含むファイル

  ■ 拡張子指定
    例: ext:jpg;gif;png
    → .jpg, .gif, .png いずれかのファイルを検索
    (セミコロンで複数指定)

  ■ 除外検索 (! プレフィックス)
    例: report !backup
    → 「report」を含むが「backup」を含まないファイル


================================================================================
  詳細検索
================================================================================

  ツールバーの [▼ 詳細] ボタンで詳細検索パネルを展開できます。

  - 大文字小文字を区別 ... 大文字/小文字を区別して検索
  - 拡張子           ... 拡張子でフィルタ (例: .pdf)
  - 日付             ... 更新日時の範囲を指定
  - フォルダ         ... 検索対象フォルダを限定
    - サブフォルダも検索する (チェック可)
  - サイズ           ... ファイルサイズの範囲を指定 (KB単位)
  - [条件クリア]     ... すべての詳細条件をリセット


================================================================================
  プレビュー
================================================================================

  ツールバーの [プレビュー] ボタンでプレビューパネルを表示/非表示にします。
  検索結果からファイルを選択すると、右側にプレビューが表示されます。

  ■ 対応形式
    - PDF        ... 全ページをスクロールで閲覧可能
    - 画像       ... PNG, JPG, GIF, BMP, TIFF, ICO, WebP 等
    - Office文書 ... Word, Excel, PowerPoint
                     (対応するプレビューハンドラーがインストールされている場合)
    - テキスト   ... .txt 等

  プレビューパネルの幅はスプリッターをドラッグして調整できます。


================================================================================
  お気に入り
================================================================================

  よく使う検索条件を保存して、すぐに呼び出せます。

  ■ 保存
    検索条件を設定した状態で、ツールバー右側の [保存] ボタンをクリック

  ■ 呼び出し
    ★ アイコン横のドロップダウンからお気に入りを選択

  ■ 削除
    ドロップダウンで選択した状態で [削除] ボタンをクリック

  お気に入りの詳細な編集は [設定] → [お気に入り] タブから行えます。


================================================================================
  右クリックメニュー
================================================================================

  検索結果を右クリックすると、以下のメニューが表示されます。

  - 開く           ... ファイルを既定のアプリで開く
  - フォルダを開く ... ファイルのあるフォルダをエクスプローラーで開く
  - フルパスをコピー ... ファイルの完全なパスをクリップボードにコピー
  - プロパティ     ... Windows のファイルプロパティダイアログを表示


================================================================================
  キーボードショートカット
================================================================================

  Ctrl + F   ... 検索ボックスをクリアしてフォーカス
  Escape     ... 検索ボックスをクリア


================================================================================
  設定
================================================================================

  ツールバーの [設定] ボタンから設定ダイアログを開きます。

  ■ ドライブタブ
    - ローカルドライブ (NTFS) の有効/無効
    - ネットワークドライブの有効/無効
    - [ドライブ更新] ... 新しく接続されたドライブを再検出
    - 最大検索結果数 (既定: 100,000件)
    - ネットワーク再スキャン間隔 (分, 0で無効)
    - 隠しファイルを除外
    - システムファイルを除外
    - 除外フォルダ (1行に1つ、既定: $Recycle.Bin, System Volume Information)

  ■ お気に入りタブ
    - お気に入りフィルタの作成・編集・削除


================================================================================
  ネットワークドライブ
================================================================================

  マップされたネットワークドライブ (Z:\\ 等) を検索対象に追加できます。
  ネットワークドライブのスキャンには通常のファイル列挙を使用するため、
  ローカルドライブ (MFT) より時間がかかります。

  設定で再スキャン間隔を指定すると、定期的にネットワークドライブの
  インデックスを更新します (既定: 5分)。


================================================================================
  技術情報
================================================================================

  - NTFS Master File Table (MFT) を直接読み取り、高速なインデックス作成
  - USN Journal によるファイル変更のリアルタイム監視
  - 並列ブルートフォース検索エンジン
  - 単一EXEファイル、外部依存なし
  - PDF描画は Windows 組み込みの Windows.Data.Pdf API を使用
    (Adobe Acrobat 不要)
