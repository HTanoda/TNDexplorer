================================================================================
  TNDexplorer - 超高速ファイル検索ツール
  Version 1.3.1.2
================================================================================

  NTFS MFT を直接読み取ることで、数百万件のファイルを瞬時に検索できる
  Windows デスクトップアプリケーションです。ネットワークドライブにも対応。
  ファイル名検索だけでなく、ファイルの中身を直接読み取る内容検索にも対応。

  Copyright (c) 2026 TND (Hiroki Tanoda)
  License: MIT


================================================================================
  動作要件
================================================================================

  - Windows 10 / 11
  - .NET Framework 4.8 (Windows 10 1903以降は標準搭載)
  - 管理者権限 (NTFS MFT へのアクセスに必要)


================================================================================
  インストール / 起動
================================================================================

  TNDexplorer.exe を任意のフォルダに配置し、ダブルクリックで起動してください。
  単一EXEファイルで動作し、外部依存ファイルはありません。

  初回起動時に UAC (ユーザーアカウント制御) の確認が表示されます。
  「はい」を選択すると、初期設定ウィザードが開きます。

  ■ 初期設定ウィザード
    - 「このアプリをインストールしますか？」の確認が表示されます
    - インデックス対象のローカルドライブ(NTFS)を選択
    - 「開始」ボタンでインストールとインデックス作成を開始
    ※ インストールにより Windows の「プログラムと機能」に登録されます。
      資産管理ツール (AssetView 等) からも検出可能になります。
    ※ ネットワークドライブや共有フォルダは、起動後に
      [設定] → [ドライブ] → [フォルダ] から手動で追加できます。

  設定は %LOCALAPPDATA%\TNDexplorer\ に保存されます。

  ■ アンインストール
    Windows の「プログラムと機能」（設定 > アプリ > インストールされているアプリ）
    から通常のソフトウェアと同じ手順でアンインストールできます。
    コマンドラインから TNDexplorer.exe --uninstall でも実行可能です。
    ※ EXE ファイル自体は手動で削除してください。


================================================================================
  基本的な使い方
================================================================================

  1. 起動するとインデックスの作成が始まります(ステータスバーに進捗表示)
  2. 上部の検索ボックスにキーワードを入力
  3. リアルタイムで検索結果が表示されます
  4. 結果をダブルクリックするとファイルが開きます

  ■ フィルタ (検索ボックス右側)
    [すべて]  [ファイル]  [フォルダ]
    表示する項目の種類を切り替えます。


================================================================================
  検索構文
================================================================================

  ■ AND検索 (スペース区切り)
    例: report 2024
    → 「report」と「2024」の両方を含むファイル名を検索

  ■ OR検索 (パイプ | 区切り)
    例: ext:txt|ext:doc
    → .txt または .doc のファイルを検索

  ■ AND + OR の組み合わせ
    例: ext:txt|ext:doc report
    → (.txt または .doc) かつ「report」を含むファイル

  ■ 拡張子指定
    例: ext:jpg;gif;png
    → .jpg, .gif, .png いずれかのファイルを検索
    (セミコロンで複数指定)

  ■ 除外検索 (! プレフィックス)
    例: report !backup
    → 「report」を含むが「backup」を含まないファイル


================================================================================
  内容検索（ファイルの中身を検索）
================================================================================

  ツールバーの [内容検索] ボタンで内容検索モードに切り替えられます。
  ファイル名ではなく、ファイルの中身（テキスト）を直接検索します。
  事前のインデックス構築は不要で、検索実行時にリアルタイムで読み取ります。

  ■ 使い方
    1. [内容検索] ボタンをクリックしてON
    2. 詳細パネルで検索対象のフォルダを指定（推奨）
    3. キーワードを入力して Enter
    4. ファイルの中身を並列スキャンし、マッチした箇所を表示

  ■ 対応ファイル形式
    - テキストファイル   ... .txt, .csv, .log, .xml, .json, .html 等
    - Office文書        ... Word (.docx), Excel (.xlsx), PowerPoint (.pptx)
                           OpenXML形式から直接テキスト抽出（Office不要）
    - PDF              ... テキストベースのPDFから内容を抽出
    - その他           ... IFilter対応形式（Officeがインストールされている場合）

  ■ オプション（設定 → 内容検索タブ）
    - 対象拡張子       ... 内容検索の対象とする拡張子を指定
    - 最大ファイルサイズ ... スキャン対象の上限サイズ (既定: 50MB)

  ■ ファイル名も同時に検索
    設定でファイル名も同時に検索するオプションを有効にすると、
    内容検索モードでもファイル名にマッチするファイルを結果に含めます。

  ■ ヒント
    - フォルダ範囲を絞ると高速に検索できます
    - 拡張子フィルタで対象を限定するとさらに効率的です
    - 進捗状況はステータスバーに表示されます


================================================================================
  詳細検索
================================================================================

  ツールバーの [▼ 詳細] ボタンで詳細検索パネルを展開できます。

  - 大文字小文字を区別 ... 大文字/小文字を区別して検索
  - 拡張子           ... 拡張子でフィルタ (例: .pdf)
  - 日付             ... 更新日時の範囲を指定
  - フォルダ         ... 検索対象フォルダを限定
    - サブフォルダも検索する (チェック可)
  - サイズ           ... ファイルサイズの範囲を指定 (KB単位)
  - [条件クリア]     ... すべての詳細条件をリセット


================================================================================
  プレビュー
================================================================================

  ツールバーの [プレビュー] ボタンでプレビューパネルを表示/非表示にします。
  検索結果からファイルを選択すると、右側にプレビューが表示されます。

  ■ 対応形式
    - PDF        ... 全ページをスクロールで閲覧可能
    - 画像       ... PNG, JPG, GIF, BMP, TIFF, ICO, WebP 等
    - Office文書 ... Word, Excel, PowerPoint
                     (対応するプレビューハンドラーがインストールされている場合)
    - テキスト   ... .txt 等

  プレビューパネルの幅はスプリッターをドラッグして調整できます。


================================================================================
  お気に入り
================================================================================

  よく使う検索条件を保存して、すぐに呼び出せます。

  ■ 保存
    検索条件を設定した状態で、ツールバー右側の [保存] ボタンをクリック

  ■ 呼び出し
    ★ アイコン横のドロップダウンからお気に入りを選択

  ■ 削除
    ドロップダウンで選択した状態で [削除] ボタンをクリック

  お気に入りの詳細な編集は [設定] → [お気に入り] タブから行えます。


================================================================================
  右クリックメニュー
================================================================================

  検索結果を右クリックすると、以下のメニューが表示されます。

  - 開く           ... ファイルを既定のアプリで開く
  - フォルダを開く ... ファイルのあるフォルダをエクスプローラーで開く
  - フルパスをコピー ... ファイルの完全なパスをクリップボードにコピー
  - ファイルをコピー ... ファイル自体をクリップボードにコピー（貼り付けで複製）
  - プロパティ     ... Windows のファイルプロパティダイアログを表示


================================================================================
  キーボードショートカット
================================================================================

  Ctrl + F   ... 検索ボックスをクリアしてフォーカス
  Escape     ... 検索ボックスをクリア


================================================================================
  設定
================================================================================

  ツールバーの [設定] ボタンから設定ダイアログを開きます。

  ■ 全般タブ
    - 最大検索結果数 (既定: 100,000件)
    - 隠しファイルを除外
    - システムファイルを除外

  ■ ドライブタブ
    - ローカルドライブ (NTFS) の有効/無効
    - フォルダの手動追加 (ネットワークドライブ、共有フォルダ等)
      UNCパス (\\server\share) またはドライブレター (K:\folder) で指定可能
    - リスキャン設定
        - 1日1回（スケジュール）: 指定時刻に自動更新 (既定: 12:30)
        - 一定間隔でリスキャン: 指定分数ごとに自動更新
        - 手動のみ: 自動リスキャンなし
      [すぐに更新] ボタンで選択したフォルダのみリスキャン可能
      [すべて更新] ボタンで全フォルダを一括リスキャン
    - 除外フォルダ (1行に1つ、既定: $Recycle.Bin, System Volume Information)

  ■ お気に入りタブ
    - お気に入りフィルタの作成・編集・削除

  ■ 内容検索タブ
    - 対象拡張子 (内容検索でスキャンするファイルの拡張子)
    - 最大ファイルサイズ (既定: 50MB)


================================================================================
  ネットワークドライブ / 共有フォルダ
================================================================================

  ネットワーク上の共有フォルダを検索対象に追加できます。

  ■ 追加方法
    [設定] → [ドライブ] → [フォルダ] → [追加] ボタンから
    検索対象のフォルダを手動で追加してください。
    UNCパス (\\server\share) とドライブレター (K:\folder) の両方に対応。

  ■ スキャンとキャッシュ
    ネットワークフォルダのスキャンには通常のファイル列挙を使用するため、
    ローカルドライブ (MFT) より時間がかかります。
    スキャン結果はキャッシュに保存され、次回起動時に再利用されるため、
    毎回フルスキャンが発生することはありません。

  ■ リスキャン設定
    ネットワークフォルダのインデックスを自動更新するタイミングを
    3つのモードから選択できます。

    ・1日1回（スケジュール）
      指定した時刻に1日1回自動更新します (既定: 12:30)。
      ファイルサーバーへの負荷を最小限に抑えます。
      アプリ起動時に実行予定時刻を過ぎていた場合は自動で追いつきます。

    ・一定間隔でリスキャン
      指定した分数ごとに自動更新します。

    ・手動のみ
      自動更新は行いません。
      設定画面の [すべて更新] ボタンで手動更新してください。
      特定のフォルダだけ更新したい場合は、一覧で選択して [すぐに更新] を
      クリックしてください。

  ■ 内容検索とネットワーク負荷
    ネットワークフォルダに対して内容検索を実行すると、
    大量のファイル読み取りが発生しファイルサーバーに負荷がかかるため、
    実行前に確認ダイアログが表示されます。
    フォルダの範囲と拡張子を絞ってご利用ください。


================================================================================
  技術情報
================================================================================

  - NTFS Master File Table (MFT) を直接読み取り、高速なインデックス作成
  - USN Journal によるファイル変更のリアルタイム監視
  - 並列ブルートフォース検索エンジン
  - 内容検索: リアルタイムgrep方式 (事前インデックス不要)
    - OpenXML直接解析によるOffice文書テキスト抽出 (Office不要)
    - PDFテキスト抽出 (FlateDecode解凍 + ToUnicode CMap対応)
    - IFilter COM フォールバック
  - ネットワークキャッシュ: 独自バイナリ形式 (TNDc) によるコンパクトな
    キャッシュ保存。アトミック書き込み (一時ファイル＋リネーム) で
    データ破損を防止。アプリ終了時にキャッシュを自動保存。
  - ドライブレター変換: UAC昇格環境でもネットワークドライブの
    ドライブレター (K:\ 等) を正しく解決
  - リスキャンスケジューラ: 1日1回/一定間隔/手動の3モード対応。
    見逃したスケジュールの自動キャッチアップ機能付き
  - 単一EXEファイル、外部依存なし
  - PDF描画は Windows 組み込みの Windows.Data.Pdf API を使用
    (Adobe Acrobat 不要)
